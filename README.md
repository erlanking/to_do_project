# to_do_project

`TaskFlow` — это мобильное приложение для управления личными задачами, разработанное на Flutter (Android/iOS) с подключением к backend на FastAPI по REST API. Приложение поддерживает полный цикл работы пользователя: регистрацию, вход по JWT, сохранение сессии, просмотр только своих задач, создание новых задач, редактирование, удаление и отметку выполнения через checkbox с визуальным вычеркиванием.

В проекте реализована чистая структура по слоям (`screens`, `services`, `models`), асинхронная работа через `async/await`, обработка сетевых и серверных ошибок, а также хранение токена в `SharedPreferences` для автоматического входа после перезапуска приложения. Интерфейс построен на Material 3, адаптирован под разные размеры экранов, поддерживает светлую/темную тему, поиск по задачам, pull-to-refresh и локализацию на русском и английском языках.

Проект подойдет как учебный пример полноценного Flutter CRUD-приложения с авторизацией и реальным backend-взаимодействием, а также как базовый шаблон для дальнейшего развития (категории, приоритеты, дедлайны, уведомления, офлайн-режим).
